# Accountant quick start

Open the Markus folder in Cursor. Start a new Agent chat. You can say **I am an accountant**, then describe the job in ordinary words (for example: import last month's supplier invoices, add a cash receipt, download the period pack).

Markus will show a preview before it changes anything. Read it. If it looks right, say yes. If it looks wrong, say what the correct result should be.

If a flow is missing a step or only half-right, say so. Markus will check and correct itself. After a code change, you may be asked to reload Markus in Cursor (Command Palette → **Reload MCP servers**), then try the same job again.

You do not need the terminal or Git.
